# CURRENT demo — Blink teacher

Open [https://workshop.thecosmoslabs.com](https://workshop.thecosmoslabs.com) → **App**.

1. CURRENT asks what you want to build — say **Blink** (or click **Start Blink**).
2. Follow the Sequence rail; the 3D Nano highlights D13 / GND for the active step.
3. Arm Continuity Camera on the breadboard; watch Cosmos ms + twin JSON.
4. Hold the mic to dictate questions (Canary ASR) or type “next” / polarity questions.
5. Finish: D13 → 220Ω → LED anode; cathode → GND; upload Arduino Blink.

Judging angle: proactive teacher (not a plan reader) + live Cosmos vision + Canary voice + W&B tips + VAST history, on CoreWeave GPUs.
