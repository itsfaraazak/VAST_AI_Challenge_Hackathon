# Live Twin — verified electronics coach

Proactive breadboard coach on the VAST Builders stack.

- **Phone** streams JPEG + mic WAV; **laptop** shows twin graph, verifier findings, guidance.
- **YOLO** = change trigger; **Cosmos3-Reason** (`image_url`) = twin JSON; **Canary** = ASR.
- **Deterministic verifier** (MNA + rules + optional Z3) gates every spoken tip.
- **W&B** phrases tips only (`meta-llama/Llama-3.1-8B-Instruct`).
- Deploy: `bash deploy.sh` → open https://workshop.thecosmoslabs.com → **App**.

See `DEMO.md` for the 2-minute pitch. Replay: **Shift+R** on the laptop view.
